# Security reports

If you find a security problem, please arrange private contact with the repository
owner before posting exploit details or sensitive logs. If GitHub offers **Report
a vulnerability** for this repository, use it. Otherwise, open an issue asking for
a private reporting channel without including the vulnerability details.

Never upload a CA signing key, broker/device private key, registration token,
Wi-Fi password or installation bundle. Check log excerpts before sharing them.

This project is experimental. Use the latest release and keep HA, your MQTT
broker and the host operating systems updated. No support window or security
response time is promised yet.
